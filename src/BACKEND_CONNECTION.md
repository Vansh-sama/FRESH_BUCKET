# Fresh Basket Mobile Backend Connection

The UI is preserved. The app now uses the Fresh Basket backend for customer authentication, categories, products, orders and order tracking.

## Local Android emulator
Backend: `http://10.0.2.2:5000`
API: `http://10.0.2.2:5000/api/v1`

## Local iOS simulator
Backend: `http://localhost:5000`
API: `http://localhost:5000/api/v1`

## Production
Release builds use:
`https://fresh-bucket-web.onrender.com/api/v1`

The mobile app no longer uses hardcoded product/category/order demo data for the connected flows.
